# サーバーレス・マイクロサービス 回答

1. A - S3 イベントと Lambda はイベント駆動処理に適します。
2. A - API Gateway は API 入口、Lambda は処理本体として使えます。
3. A - Step Functions は順序、条件分岐、リトライを管理できます。
4. A - Kubernetes 不要なら ECS がシンプルな選択肢です。
5. A - Kubernetes エコシステムが必要なら EKS を検討します。
6. A - Fargate はサーバーレスコンテナ実行基盤です。
7. A - ECR はコンテナイメージレジストリです。
8. A - Lambda には実行時間やコールドスタートなどの制約があります。
9. A - API タイプごとに機能と料金が異なります。
10. A - 曖昧なタグ運用は追跡性を下げます。
