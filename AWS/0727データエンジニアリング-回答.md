# データエンジニアリング 回答

1. A - S3 はデータレイクの保存先としてよく使われます。
2. A - S3 上のデータを SQL 分析するには Athena が適します。
3. A - Glue Crawler はスキーマ推定とカタログ登録に使えます。
4. A - Athena はスキャン量課金なので形式とパーティションが重要です。
5. A - 本格的な DWH 分析には Redshift が向きます。
6. A - リアルタイムストリーミングには Kinesis が候補です。
7. A - Kafka 互換が必要なら MSK を検討します。
8. A - データレイクの権限統制には Lake Formation が使えます。
9. A - ファイル転送や同期には DataSync が適します。
10. A - DB 移行と継続レプリケーションには DMS が適します。
