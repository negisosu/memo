# データエンジニアリングの AWS サービス

## 概要

データエンジニアリングでは、データの保存、取り込み、変換、ストリーミング処理、分析、可視化、移行を組み合わせてデータパイプラインを作ります。

| 目的 | 主なサービス |
|---|---|
| データを保存する | Amazon S3 |
| ETL とカタログを管理する | AWS Glue |
| S3 データを SQL 分析する | Amazon Athena |
| DWH で分析する | Amazon Redshift |
| ストリーミングデータを扱う | Amazon Kinesis |
| Kafka をマネージドで使う | Amazon MSK |
| データレイクを管理する | AWS Lake Formation |
| BI 可視化を行う | Amazon QuickSight |
| ファイル転送を行う | AWS DataSync |
| データベース移行を行う | AWS DMS |

## Amazon S3

Amazon S3 は、オブジェクトストレージサービスです。大量の非構造化・半構造化データを保存でき、データレイク、バックアップ、ログ保管、静的コンテンツ配信などに使います。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| オブジェクト保存 | ファイルをオブジェクトとしてバケットに保存する。 |
| 高耐久性 | 長期保存に向く高い耐久性を提供する。 |
| ストレージクラス | Standard、IA、Glacier 系など用途別に選べる。 |
| ライフサイクル | 古いデータを低コスト層へ移動できる。 |
| 多サービス連携 | Athena、Glue、CloudFront、Lambda などと連携する。 |

### 利用例

| シーン | 内容 |
|---|---|
| データレイク | 生データ、加工済みデータ、分析用データを保存する。 |
| ログ保管 | ALB、CloudTrail、VPC Flow Logs などを保存する。 |
| バックアップ | DB エクスポートやファイルバックアップを保存する。 |
| 静的配信 | CloudFront と組み合わせて静的サイトを配信する。 |

### 向いている利用シーン

- 大量データを低コストで保存したい
- 分析基盤の保存先を作りたい
- ログやバックアップを長期保存したい

### 注意点

S3 はオブジェクトストレージであり、ファイルシステムやブロックストレージとは挙動が異なります。権限、暗号化、ライフサイクルを設計します。

## AWS Glue

AWS Glue は、データカタログ、ETL、データ変換、クローラーを提供するマネージドデータ統合サービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| Data Catalog | テーブル定義やスキーマ情報を管理する。 |
| Crawler | S3 などのデータをスキャンしてスキーマを推定する。 |
| ETL ジョブ | Spark などでデータ変換処理を実行する。 |
| サーバーレス | ETL 実行基盤のサーバー管理を減らせる。 |

### 利用例

| シーン | 内容 |
|---|---|
| ログ整形 | 生ログを Parquet 形式に変換する。 |
| カタログ作成 | S3 上のデータを Athena で参照できるようにする。 |
| データ統合 | 複数ソースのデータを分析用に加工する。 |

### 向いている利用シーン

- S3 データを分析しやすく整形したい
- データカタログを管理したい
- サーバーレス ETL を実行したい

### 注意点

ETL ジョブは処理時間や DPU によってコストが変わります。小規模な単純変換なら Lambda や Athena CTAS で足りる場合もあります。

## Amazon Athena

Amazon Athena は、S3 上のデータを SQL で直接クエリできるサーバーレス分析サービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| サーバーレス SQL | クラスター管理なしで SQL 分析できる。 |
| S3 直接分析 | S3 の CSV、JSON、Parquet などをクエリする。 |
| Glue 連携 | Glue Data Catalog のテーブル定義を使う。 |
| スキャン量課金 | 読み込んだデータ量に応じて課金される。 |

### 利用例

| シーン | 内容 |
|---|---|
| ログ分析 | CloudTrail や ALB ログを SQL で調べる。 |
| アドホック分析 | 一時的に S3 データを確認する。 |
| データレイク検索 | 加工済み Parquet データを分析する。 |

### 向いている利用シーン

- S3 上のデータを簡単に SQL 分析したい
- クラスター管理をしたくない
- ログやデータレイクの探索をしたい

### 注意点

スキャン量で課金されるため、Parquet などの列指向形式、パーティション設計、圧縮が重要です。

## Amazon Redshift

Amazon Redshift は、大量データを高速に分析するためのデータウェアハウスサービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| DWH | 大量データの集計・分析に向く。 |
| 列指向 | 分析クエリに強い。 |
| Redshift Spectrum | S3 上のデータも外部テーブルとして分析できる。 |
| BI 連携 | QuickSight などから接続できる。 |

### 利用例

| シーン | 内容 |
|---|---|
| 売上分析 | 注文、顧客、商品データを集計する。 |
| BI 基盤 | ダッシュボード用の集計データを提供する。 |
| 大規模分析 | 数十 TB 以上のデータを分析する。 |

### 向いている利用シーン

- 継続的な分析基盤が必要
- 複雑な集計クエリを高速化したい
- BI ユーザーが多数いる

### 注意点

小規模・一時的な分析なら Athena の方が簡単な場合があります。Redshift はデータモデリング、ロード、チューニングを考慮します。

## Amazon Kinesis

Amazon Kinesis は、リアルタイムストリーミングデータを収集・処理するサービス群です。ログ、クリックストリーム、IoT データなどを継続的に扱います。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| ストリーミング | データをリアルタイムに取り込む。 |
| Data Streams | アプリケーションがストリームを読み取って処理する。 |
| Data Firehose | S3、Redshift、OpenSearch などへ配信する。 |
| Data Analytics | ストリームに対してリアルタイム分析する。 |

### 利用例

| シーン | 内容 |
|---|---|
| ログ収集 | アプリログをリアルタイムに S3 へ保存する。 |
| クリック分析 | Web 行動ログをリアルタイム分析する。 |
| IoT データ | センサーデータを継続的に取り込む。 |

### 向いている利用シーン

- リアルタイムデータを扱いたい
- 継続的に発生する大量イベントを処理したい
- S3 や Redshift に自動配信したい

### 注意点

順序性、シャード、スループット、保持期間を設計します。Kafka 互換が必須なら MSK を検討します。

## Amazon MSK

Amazon MSK は、Apache Kafka をマネージドで提供するサービスです。Kafka 互換のストリーミング基盤を AWS で運用できます。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| Kafka 互換 | 既存 Kafka アプリケーションを活かせる。 |
| マネージド運用 | ブローカー管理を AWS が支援する。 |
| 高スループット | 大量イベントの処理に向く。 |
| エコシステム | Kafka Connect、Kafka Streams などを活用できる。 |

### 利用例

| シーン | 内容 |
|---|---|
| Kafka 移行 | オンプレミス Kafka を AWS に移行する。 |
| イベント基盤 | 複数システム間のイベントストリームを扱う。 |
| リアルタイム分析 | Kafka Streams でイベント処理する。 |

### 向いている利用シーン

- Kafka 互換が必要
- 既存の Kafka エコシステムを使いたい
- 高スループットなイベント基盤が必要

### 注意点

Kafka の運用知識は必要です。AWS ネイティブでシンプルに済むなら Kinesis も候補になります。

## AWS Lake Formation

AWS Lake Formation は、S3 を中心としたデータレイクの構築、権限管理、カタログ管理を支援するサービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| データレイク管理 | S3 上のデータレイク構築を支援する。 |
| 権限管理 | テーブル、列、行レベルでアクセス制御できる。 |
| Glue 連携 | Glue Data Catalog を基盤にする。 |
| 監査 | データアクセスの統制に使える。 |

### 利用例

| シーン | 内容 |
|---|---|
| 部門別制御 | 営業、経理、分析チームで参照できる列を分ける。 |
| データレイク統制 | S3 データへのアクセス管理を標準化する。 |
| 分析基盤 | Athena、Redshift Spectrum、Glue から同じカタログを使う。 |

### 向いている利用シーン

- S3 データレイクの権限管理が複雑
- 部門や役割ごとにアクセスを分けたい
- 分析基盤を統制したい

### 注意点

IAM、S3 バケットポリシー、Glue 権限との関係を理解して設計します。

## Amazon QuickSight

Amazon QuickSight は、AWS の BI・可視化サービスです。S3、Athena、Redshift、RDS などのデータからダッシュボードを作成できます。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| BI 可視化 | グラフ、表、ダッシュボードを作成する。 |
| 多様なデータソース | Athena、Redshift、RDS、S3 などに接続できる。 |
| SPICE | 高速分析用のインメモリエンジンを利用できる。 |
| 共有 | 組織内でダッシュボードを共有できる。 |

### 利用例

| シーン | 内容 |
|---|---|
| 売上ダッシュボード | Redshift の集計結果を可視化する。 |
| ログ可視化 | Athena で集計したログをダッシュボード化する。 |
| 経営レポート | KPI を定期的に確認する。 |

### 向いている利用シーン

- 分析結果を非エンジニアにも見せたい
- AWS 内のデータを可視化したい
- ダッシュボードを共有したい

### 注意点

データモデルや権限設計が不十分だと、利用者に不要なデータが見える可能性があります。

## AWS DataSync

AWS DataSync は、オンプレミスストレージ、他クラウド、AWS ストレージ間でデータを効率的に転送するサービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| ファイル転送 | NFS、SMB、S3、EFS、FSx などに対応する。 |
| 高速転送 | 大量ファイルを効率よく転送できる。 |
| スケジュール | 定期的な同期を設定できる。 |
| 検証 | 転送データの整合性確認を行える。 |

### 利用例

| シーン | 内容 |
|---|---|
| データ移行 | オンプレミス NAS から S3 へ移行する。 |
| バックアップ | ファイルサーバーのデータを AWS に定期同期する。 |
| 分析投入 | 社内ファイルを S3 データレイクへ転送する。 |

### 向いている利用シーン

- 大量ファイルを AWS に移したい
- 定期的にストレージ間同期したい
- 手作業の転送を減らしたい

### 注意点

DB のスキーマ変換や継続レプリケーションには DMS など別サービスが向きます。

## AWS DMS

AWS DMS は、データベースを AWS へ移行したり、継続的にレプリケーションしたりするサービスです。

### 主な特徴

| 特徴 | 説明 |
|---|---|
| DB 移行 | オンプレミス DB から RDS、Aurora、Redshift などへ移行する。 |
| 継続レプリケーション | 移行中も変更データを同期できる。 |
| 異種 DB 対応 | 一部の異なる DB エンジン間移行に対応する。 |
| SCT 連携 | スキーマ変換には Schema Conversion Tool を使う。 |

### 利用例

| シーン | 内容 |
|---|---|
| RDS 移行 | Oracle や MySQL を RDS / Aurora に移行する。 |
| 最小停止移行 | 既存 DB の変更を同期しながら移行する。 |
| DWH 投入 | 業務 DB から Redshift へデータを連携する。 |

### 向いている利用シーン

- データベースを AWS に移行したい
- 移行時の停止時間を短くしたい
- 継続的な DB レプリケーションが必要

### 注意点

DMS はデータ移行が中心です。アプリケーション互換性、SQL 差異、性能検証、スキーマ変換は別途確認します。

## 使い分けの目安

| やりたいこと | 主な候補 |
|---|---|
| データレイクの保存先を作りたい | S3 |
| ETL とカタログ管理をしたい | Glue |
| S3 を SQL で分析したい | Athena |
| 本格的な DWH を作りたい | Redshift |
| リアルタイムデータを処理したい | Kinesis |
| Kafka 互換が必要 | MSK |
| データレイクの権限を統制したい | Lake Formation |
| 分析結果を可視化したい | QuickSight |
| ファイルを転送したい | DataSync |
| DB を移行したい | DMS |
